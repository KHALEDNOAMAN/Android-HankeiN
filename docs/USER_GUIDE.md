# Android HankeiN - User Guide

## What is HankeiN?
HankeiN is an Android application for radius-based area calculation and mapping.

## Setup
```bash
git clone https://github.com/takumi-sato0209/Android-HankeiN.git
# Open in Android Studio
# Build and run on emulator or device
```

## Features
| Feature | Description |
|---------|-------------|
| Radius Input | Set custom radius in meters/km |
| Map View | Visual circle overlay on map |
| Area Calc | Automatic area calculation |
| Location | GPS-based center point |

## Requirements
- Android 8.0 (API 26) or higher
- Google Maps API key
- Location permissions

## Building from Source
1. Open in Android Studio
2. Add Google Maps API key to local.properties
3. Sync Gradle
4. Run on device/emulator
